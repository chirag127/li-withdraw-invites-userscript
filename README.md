# LinkedIn Withdraw Invites

Withdraws pending invitations in bulk with a dry run, confirm and per-invite log.

## Install

Follow the [install guide](https://github.com/chirag127/userscript-install-guide), then install:

```
https://github.com/chirag127/li-withdraw-invites-userscript/raw/main/li-withdraw-invites-userscript.user.js
```

## Usage

Open Manage invitations → Sent, press the ↩ chip (Alt+W), Dry run first, then Withdraw.

## Limits

- Driven through the UI because no stable endpoint exists
- One page at a time
- LinkedIn may rate-limit after a few hundred
